四类能力会话，各干各的活

聊天是聊天，生成是生成——不同任务各有独立界面与存档，互不打架

💬

对话

多服务商档案与模型池路由，分支树、全文搜索、自动压缩，缓存保温省钱

🖼️

生图

图生图与参数面板，参考图直接喂给模型，多张产出一次到位

🎬

视频

文本/图像/视频转视频三模式，首尾帧精确控制，比例时长分辨率随调

🎵

音乐

多家族 API 自动探测，描述或歌词直出成曲，就地试听

工具能干活，也要守规矩

每一步执行都有规则、审批与审计兜底——能力越强，收容越紧

🧰

工具系统

读写、命令、网络检索等内置工具；模型在你的工作目录里真正动手干活

🛡️

逐调用沙箱

命令在低完整性沙箱与 Job Object 收容下执行，规则库 + 审批（单次放行 / 总是允许）说了算

📜

审计中心

敏感信息自动打码，删除进回收站并有自动备份兜底，出了事能回溯

👁️

多模态识别

图片、视频、音频本体随行发给支持的模型——看图听音，按能力逐个放行

🤖

MCP 扩展

stdio / HTTP 服务器即插即用，支持 OAuth 接入，工具总开关一键收放

🎯

目标模式

给一个目标，模型带着判据清单自主推进、自我修复，直到验收通过

⏰

定时任务

每周计划与 cron 表达式触发后台任务，跑完系统通知，结果进会话

🧠

记忆与知识库

长对话自动压缩，关键结论蒸馏进记忆；本地知识库随问随检索
