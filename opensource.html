本地开发

前置要求：Node.js 22+、Rust stable（MSVC 工具链）、Windows 10/11

# 安装前端依赖
npm install

# 本地开发（前端热更新 + Rust 增量编译）
npm run tauri dev

# 测试：前端 vitest · 后端 cargo（1100+ 条）
npm test
cd src-tauri && cargo test --lib

# 构建 Windows 安装包（NSIS / MSI）
npm run tauri build

CI 双管道

每次 push 与 PR 自动跑：前端 tsc + vitest + vite 构建（Ubuntu）；后端 1100+ 条 cargo 测试（Windows）

📦

Tag 发布

打 v* 标签自动构建 NSIS / MSI 安装包并挂到 GitHub Release 草稿，检查附件后手动发布

🔐

依赖审计

每周自动对照 RustSec 数据库扫描 Rust 依赖的已知漏洞，报告透明可查
