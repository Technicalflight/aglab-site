工具能干活，也要守规矩

能力越强，收容越紧——每一步执行都有规则、审批与审计兜底

🧰

工具系统

读写、命令、网络检索等内置工具；模型在你的工作目录里真正动手干活，而不是纸上谈兵

🛡️

逐调用沙箱

命令在低完整性沙箱与 Job Object 收容下执行——越界即失败，失败即拒绝，不给"下次注意"的机会

✅

规则库与审批

文件、命令、网络三层规则先行；拿不准的弹审批卡，单次放行或总是允许由你拍板

📜

审计中心

敏感信息自动打码，操作留痕可回溯；删除一律进回收站，并有自动备份兜底

👁️

多模态识别

图片、视频、音频本体随行发给支持的模型——看图听音，按模型能力逐个放行

🤖

MCP 扩展

stdio / HTTP 服务器即插即用，支持 OAuth 接入远程服务；工具总开关一键收放

🎯

目标模式

给一个目标，模型带着判据清单自主推进——每一轮有产出、有验证，含强制修复轮直到验收

⏰

定时任务

每周计划与 cron 表达式触发后台任务，跑完系统通知，结果自动进会话

🧠

记忆与知识库

长对话自动压缩不爆窗口，关键结论蒸馏进记忆；本地知识库随问随检索

🔍

对话分支与搜索

重新生成长出分支而不是抹掉旧答案；跨话题全文搜索，找到那句说过的话

🔥

缓存保温

空闲时按需保温前缀缓存，长对话的重复成本降下来——默认关，开与不开你说了算

🔌

扩展生态

技能（Skills）、SSH 主机、LSP、浏览器控制（CDP）、PTC code-mode——按需扩展模型的手

设计铁律

规则层先行、能力表兜底；敏感数据钉死本地；每一条自动放行都要能被审计回溯。
模型的能力可以放开，但收容的边界由用户定义。
