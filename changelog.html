v0.2.3 🚀 最新 2026-10-07
新增
  • 知识库导入扩容：docx/xlsx/pptx 就地解析（段落/表格/幻灯片保序），PDF 与图片自动走 OCR 提取文字；二进制类上限放宽到 32MB，来源标注提取方式
  • 内置 Umi-OCR 引擎（MIT 协议）：设置 → 数据 → 资料库检索 一键下载官方 Paddle 整合包（约 134MB，gh-proxy 镜像、无需代理）并后台启动；也支持自行安装只填服务地址
  • 检索 Rerank 精排（可选）：配重排模型后，融合候选扩 4 倍送端点 /rerank 精排再取回最优几条；没配或失败自动回落融合序
  • 对话导出：顶栏导出 Markdown（人读）/ JSON（整段结构）/ JSONL（Unsloth 微调格式），只导当前分支的用户+助手正文
修复
  • 切换模型后上下文用量卡容量不同步：容量解析现在读当前选中模型的勾选表行，切模型即时跟手；旧模型那轮的台账读数不再压住新容量（切到 1M 窗口的模型卡片不再挂 128K）
  • 记忆页「待确认候选」按钮贴边：候选行与批量操作行的左右留白补到与设置页其他卡片一致
  • Umi-OCR 协议标注改正（主程序 MIT，内置 PaddleOCR 引擎 Apache-2.0）
v0.2.2 🚀 2026-10-07
新增
  • 全球模型规格目录：档案弹窗拉取模型列表后，勾选的模型按公开规格数据自动识别多模态能力、工具调用、推理能力与上下文窗口/最大输出并预填；规格随档案落盘，全应用的能力判定同步生效
  • 模型名模糊匹配：-preview、日期尾缀（gpt-4o-2024-11-20）、命名空间（minimax/m3-preview）、分隔符差异（claude-sonnet-4-5 与 4.5）都认得，版本不同不硬凑
  • 左列模型亮能力徽章（视觉/工具/推理/生图…），分类分组与窗口读数按规格优先
  • 多模态三开关（图像/视频/音频）按规格数据自动勾选
修复
  • 资料库页与创建弹窗的下拉框：点击行内空白处不再误拉开
  • omni 全模态模型（MiniMax-M3 这类）被错进「视频」组、能力声明缺「对话」的问题；目录加载完成前勾选的模型，读数自动回填
v0.2.1 🚀 2026-10-07
新增
  • 资料库语义检索（自定义 embedding）：设置 → 数据 → 资料库检索，配一个 OpenAI 兼容 /embeddings 端点后，入库文档自动切块建向量索引（800 字/块，本地 SQLite 向量库随资料库一起迁移）；检索时关键词与向量两路 RRF 融合排序，未配置或请求失败自动退回纯关键词，原有行为不变
  • 端点模型自动识别：一键拉取端点 /models 目录，在下拉里挑 embedding 模型；手填任意模型名也行
  • 专用 API 密钥：embedding 独立凭据条目，与主密钥/各服务商档案槽完全隔离——换档案、换主密钥都不牵连语义检索；不设则沿用当前档案主密钥
  • Repo Wiki 导入：资料库页新标签，填 owner/repo 或完整 GitHub URL，浅克隆 <repo>.wiki.git，每页 Markdown 入库（Home 页排最前）并自动排入语义索引；私有仓库走本机 git 已有凭据
  • 向量维度 0 = 首次嵌入自动探测；换模型一键「重建索引」，索引状态随时可查
修复
  • 资料库检索设置页满幅铺开、控件贴边——内容列回到与各设置页一致的宽度与边距
v0.2.0 🚀 2026-10-07
新增
  • 请求链路胶囊动画：消息头行新增阶段游标——用户输入 → 载荷序列化 → 出站链路（主机 · 直连/代理）→ 服务商响应（首字节毫秒）→ 完成（token 账），随真实请求逐格游动点亮，结束后静置为徽章；带工具的回合在每次请求后重放管线
修复
  • 聊几句后选中工作目录，会话不归组：回合进行中选的工作区，收尾落盘用的是发送时的旧归属，把刚选的绑定冲回"未绑定"——现在在飞回合也带上新归属，侧栏立即归组
  • 去掉停止生成时冗余的正文提示（右上角弹窗已覆盖）；护栏截断的说明保留
v0.1.9 🚀 2026-10-07
新增
  • 中转站探针（设置 → 安全 → 中转站探针）：向中转站发少量探测请求，收集证据判断两件事——请求是否被注入额外内容、声称的目标与实际响应特征是否相符。七类信号（金丝雀回显 / 头指纹 / token 对比 / 结构校验 / 提示词泄漏 / 指令覆写 / 模型自述）、快速与深度两档、综合评分（0-100，三档结论）、历史对比（分页 / 跳页 / 详情 / 删除）、指定模型探测与多中转对照
修复
  • 失败回合后重试按钮静默失效、屏上残留重复用户消息的问题（上一版修复的根因补全）

v0.1.6 🚀 2026-10-06
修复
  • 失败回合后点重试，用户消息重复叠出：回合在问题落日志之后、完成事件之前死掉时，重试会把同一句话当新输入再发一遍——日志与屏上各叠一行。现在重试先对回日志里已落的那句问题原位重问，旧叠层一并收拢
v0.1.5 🚀 2026-10-06
修复
  • 失败回合后重试按钮静默失效：服务商报错（400/500 等）收尾时「发送中」状态没有复位，重试与输入框被静默拦下。现在回合结束即恢复，失败后可正常连点重试
  • 失败后重试成功，屏上不再残留重复的用户消息：旧失败记录归入分支历史（可切回查看），屏上保持一句问题 + 一份回答
v0.1.4 🚀 2026-10-06
新增
  • 屏幕顶部胶囊悬浮岛：电脑控制执行期间，屏幕顶部浮现「aglab 正在控制你的电脑（目标窗口）」——置顶、鼠标穿透、不抢焦点，主窗口被盖住或最小化也看得见；动作停止后 4 秒自动收起
  • 项目可移除：侧栏项目组悬停出现删除图标，两步确认后解除绑定——只解绑不碰磁盘文件，名下话题自动归入「最近」分组
v0.1.3 🚀 2026-10-06
修复
  • 新建工作目录等操作时闪出终端（cmd / powershell）：GUI 进程拉起控制台子进程（git 探测、icacls、语言服务器、MCP 服务器等）时，conhost 会给自己开一个新窗。现在全部后台子进程统一挂 CREATE_NO_WINDOW，再也不会闪
v0.1.2 🚀 2026-10-06
新增
  • 自动更新：发现新版本可一键下载安装（带签名校验），装完自动重启；检查与下载走应用代理池，不再直连 GitHub
  • 24 小时自动检查：到点联网查一次新版本，发现即弹窗提醒——设置 → 关于 aglab 里可关闭
修复
  • 「检查更新」在 GitHub 被网络屏蔽的环境下必然失败的问题（改走应用代理池）
v0.1.1 🚀 2026-10-06
新增
  • 重复循环护栏：模型偶发解码退化，在短句上无限复读（「最终。可以。」一路烧到 token 上限）。现在流式输出在进界面前先过周期检测，模式一成型（最坏约 384 字符）即自动断流——循环前的内容保留，后面的 token 不再消耗。设置 → 运行行为 可开关（默认开）
  • 上下文压缩改为居中灰色分割线：压缩中显示脉冲的「正在压缩上下文…」；完成后是一行可点开的「上下文已压缩」，摘要收在折叠区，不再占一条完整气泡。重开话题后压缩行也正确归位
修复
  • 设置页数字输入框在中文输入法下无法键盘输入的问题（WebView2 的数字输入框拒收输入法组串，已换为数字语义的文本框 + 输入过滤）
v0.1.0 🚀 2026-10-06
首发
  • aglab 开源首发（AGPL-3.0）：Windows 桌面端 AI 编程助手，Tauri 2 + React 19 + Rust
  • 四类能力会话：对话、生图、视频、音乐各有独立界面与存档，产物随话题走
  • 工具收容：逐调用沙箱（低完整性 + Job Object）、文件/命令/网络三层规则、审批卡、审计中心（敏感打码、回收站、自动备份）
  • 扩展：MCP（stdio / HTTP + OAuth）、技能 Skills、SSH 主机、LSP、浏览器控制、PTC code-mode
  • 自动化：目标模式（判据清单自主推进 + 强制修复轮）、定时任务（每周计划 + cron）、记忆与知识库、上下文自动压缩
  • 多模态：图片 / 视频 / 音频本体随行发给支持的模型；对话分支与跨话题全文搜索
  • 发布包收口：生产包不带调试面板，asset 协议收窄 + CSP，CI 最小权限
